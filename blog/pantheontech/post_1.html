Cómo levanté mi propio blog y lo saqué a internet How I set up my own blog and put it online

La idea The idea

Después de dos proyectos que ya tenía hechos (de esos hablaré en otros post), pensé que sería buena idea tener todo esto reflejado en algún sitio digital, por si a alguien le sirve, le gusta o simplemente le apetece copiarlo. Cuando trabajo en mis proyectos suelo tomar notas a papel, así que al menos para escribir esto ya tenía guía.

After two projects I already had done (I'll talk about those in other posts), I figured it would be a good idea to have all this reflected somewhere digital, in case it's useful to someone, they like it, or they just feel like copying it. When I work on my projects I usually take notes on paper, so at least for writing this I already had a guide.

El punto de partida The starting point

Tenía la idea clara, pero claro, solo he cursado el primer curso de ASIR y soy principiante en esto. La teoría que sacas de internet no basta hasta que no la haces una o varias veces y te equivocas por el camino. Así que lo que hice fue apoyarme en la IA para planificar el proyecto, aunque no siempre tenga razón y tenga que investigar o probar por mi cuenta.

I had the idea clear, but of course, I've only finished the first year of ASIR and I'm a beginner at this. The theory you get from the internet isn't enough until you've done it once or twice and made mistakes along the way. So what I did was lean on AI to plan the project, even though it isn't always right and I have to research or try things on my own.

Elegir nombre y herramientas Picking a name and the tools

Lo primero fue el nombre: "PantheonTech", porque me gusta la mitología, los gladiadores, y un poco por un nombre que usaba de pequeño en los juegos de Pokémon (eso ya se nota en el post 4).

Para construirlo elegí Astro, un generador de sitios estáticos. Instalé Node.js y Git, y desde la terminal (Windows 11) fui siguiendo los pasos: 

cd .../Desktop
npm create astro@latest
cd .../Desktop/nombreCarpeta
npm run dev

Con esto ya tenía la página corriendo en local, pero la idea era que estuviera en la nube.

The first thing was the name: "PantheonTech", because I like mythology, gladiators, and a bit because of a name I used as a kid in Pokémon games (you can already tell in post 4).

To build it I chose Astro, a static site generator. I installed Node.js and Git, and from the terminal (Windows 11) I followed the steps above. With that I had the page running locally, but the idea was for it to live in the cloud.

Publicarlo gratis Publishing it for free

No quería gastar en dominio ni hosting, así que tiré de GitHub y Cloudflare Pages. Primero adecenté mi cuenta de GitHub (foto de gladiador, nombre público "Konan", el mismo de Pokémon) y creé el repositorio "PantheonTech". Con VS Code subí la carpeta de Astro al repo. Después vinculé Cloudflare Pages a esa cuenta de GitHub: cualquier cambio en el repositorio se veía reflejado en segundos, sin gastar un euro y ya publicado en la web.

I didn't want to spend money on a domain or hosting, so I went with GitHub and Cloudflare Pages. First I tidied up my GitHub account (gladiator photo, public name "Konan", same one from Pokémon) and created the "PantheonTech" repo. With VS Code I pushed the Astro folder to it. Then I linked Cloudflare Pages to that GitHub account: any change to the repo showed up within seconds, without spending a cent, and already live on the web.

Cuando lo tiré todo abajo When I tore it all down

Técnicamente ya estaba, pero gestionar Astro sin entender su arquitectura no me resultaba nada práctico. Así que apliqué eso de "mejor malo conocido que bueno por conocer" y tiré toda la estructura de Astro para quedarme con HTML y CSS puro, que ya había trabajado en el curso y con lo que me manejo mejor.

En GitHub el cambio fue sencillo, solo sustituir archivos. En Cloudflare Pages, en cambio, me surgieron varios problemas que no logré resolver por más que investigué, así que al final rehíce todo desde cero. A veces hay que dar un paso atrás para dar dos hacia delante, y con eso ya quedó listo.

Technically it was done, but managing Astro without understanding its architecture wasn't practical at all. So I went with "better the devil you know" and tore down Astro's whole structure to keep plain HTML and CSS, which I'd already worked with during the course and handle better.

On GitHub the change was simple, just swapping files. On Cloudflare Pages, though, I ran into several problems I couldn't solve no matter how much I researched, so in the end I redid everything from scratch. Sometimes you take one step back to take two forward, and with that it was finally ready.

Qué sigue What's next

Ahora toca ir actualizando el blog con nuevos post y revisarlo de forma periódica, no solo una vez. Este ha sido el primer proyecto que publico aquí.

Now it's about keeping the blog updated with new posts and checking on it regularly, not just once. This has been the first project I've published here.
